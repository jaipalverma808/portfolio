Sign Language Capture & Illustration System

Wearable gesture recognition with sensor integration and voice output

  • Built a wearable sign-language recognition device using ESP32, flex sensors, and an MPU6050 for real-time hand-gesture detection.
  • Combined flex sensors and motion sensors to capture finger bending, hand orientation, and dynamic movement.
  • Processed sensor data and classified gestures with Embedded C/C++ on the Arduino IDE.
  • Designed a multi-modal output — recognized gestures become text, on-device illustrations, and voice output.
  • Made the system portable and usable in low light, supporting hearing- and speech-impaired communication.
